# Data

The original datasets are not included in this repository because the dermoscopic image files are large and may have separate usage terms.

Expected inputs used by the project:

- `melanoma.csv` — clinical melanoma dataset
- `HAM10000_metadata.csv` — image metadata
- HAM10000 dermoscopic image files, split into the folders used in the Colab workflow

Place the files in your working environment and update the folder paths in the code if needed.
